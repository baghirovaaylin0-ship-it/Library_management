Library Management System

Description
Library Management System is a simple desktop application developed with Python and Tkinter. It allows users to manage books and members, borrow and return books, and store data in JSON files.

Features
- Add Book
- Delete Book
- Edit Book
- Add Member
- Delete Member
- Search Books
- Borrow Book
- Return Book
- View Statistics
- Save and Load Data (JSON)

Technologies
- Python
- Tkinter
- JSON
